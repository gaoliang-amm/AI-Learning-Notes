# 04. 面试表达

## 30 秒版（电梯介绍）

> 我做了一个企业级 RAG 知识库系统——**掌柜智库**。用户上传 PDF 产品手册，系统自动解析、切分、向量化入库。查询时三路并行召回（向量+HyDE+联网），RRF 融合后 Rerank 精排，最后 LLM 生成带图片的流式回答。整套系统用 LangGraph 编排确定性流程，5500+ 行代码，支持私有化部署。

## 2-5 分钟版（系统讲解）

### 背景
企业内部产品手册多、知识分散，客服找资料效率低，传统搜索找不到精准答案。需要一套能理解自然语言、精准定位知识的智能问答系统。

### 架构
系统分为**离线导入链**和**在线查询链**两条主线：

**导入链**（7 个节点）：
1. 任务分发：根据文件类型路由到不同解析器
2. PDF 解析：MinerU 将 PDF 转为结构化 Markdown
3. 图片增强：视觉模型识别图片内容，上传 MinIO，替换 MD 中的图片引用
4. 语义切分：标题粗切 + 递归细切 + 短合并，基准 600 字符
5. 主体识别：LLM 提取文档核心主体（如"HAK180 烫金机"）
6. 向量化：BGE-M3 同时生成稠密（1024 维）+ 稀疏向量
7. 入库：写入 Milvus 双层索引（文档级 + 切片级）

**查询链**（7 个节点）：
1. 意图识别：LLM 结合历史对话识别主体 + 改写口语化问题
2. 三路并行召回：向量检索 / HyDE 假设答案检索 / MCP 联网搜索
3. RRF 融合：同源两路结果按排名加权融合
4. Rerank 精排：BGE-reranker 打分 + 动态断崖截断
5. 答案生成：LLM 基于精排结果生成答案，SSE 流式输出

### 核心亮点
- **HyDE 增强**：弱语义查询先生成假设答案再检索，召回率提升显著
- **动态截断**：不固定 TopK，而是检测分数断崖，智能截取
- **双层索引**：先圈定主体范围，再精准匹配切片，兼顾效率和精度

### 技术栈
LangGraph + FastAPI + Milvus + BGE-M3 + 通义千问 + MongoDB + MinIO + SSE

## 5-15 分钟版（深入细节）

### 背景与动机
（同上，略）

### 关键技术决策

**为什么选 LangGraph 不选原生 Agent？**
企业场景要求流程可控、可追溯、可审计。原生 Agent 自主决策会导致执行路径不可预测，LangGraph 通过显式图结构解决这个问题。

**为什么选 BGE-M3？**
单一模型同时输出稠密+稀疏向量，稠密捕捉语义，稀疏捕捉关键词，混合检索兼顾两者优势。1024 维度，支持 8192 token 上下文，130+ 语言。

**为什么需要 HyDE？**
用户提问常有"这个怎么调"这类弱语义查询。直接向量检索语义信息不足，HyDE 先让 LLM 生成假设答案（如"通过设置起点和终点实现区域控制"），拼接后语义密度大幅提升。

### 挑战与方案

**挑战 1：chunk 切分质量**
→ 标题粗切保证语义边界，递归细切控制长度，短合并减少碎片，overlap 防止断裂。参数 600/50/400/1000 通过评估系统反复调试。

**挑战 2：Rerank 模型上下文限制**
→ BGE-reranker 只有 512 token，超长内容用 LLM 压缩后打分，原始内容用于最终生成。

**挑战 3：流式输出状态管理**
→ 用 Queue 阻塞机制替代定时轮询，task_utils 管理节点状态，每次请求前清空缓存。

### 成果与收获
- 完整实现 RAG 全链路，5500+ 行工程化代码
- 掌握 LangGraph 图结构编排、多路检索融合、Rerank 精排等核心技术
- 建立了四层 RAG 评估体系，可精确定位优化方向

## STAR 法则版

### Situation（情境）
企业内部产品手册（PDF/MD）分散，客服找资料效率低，传统搜索无法理解自然语言问题。

### Task（任务）
构建一套企业级 RAG 智能问答系统，支持文档自动解析入库、多路检索、精准回答。

### Action（行动）
1. 设计 LangGraph 图结构编排导入链（7 节点）和查询链（7 节点）
2. 实现 BGE-M3 混合向量化 + Milvus 双层索引架构
3. 设计三路并行召回（向量/HyDE/MCP）+ RRF 融合 + Rerank 精排
4. 实现 SSE 流式输出 + Queue 阻塞机制
5. 建立四层 RAG 评估体系

### Result（结果）
- 完整实现从文档接入到智能问答的全链路
- 代码规模 5500+ 行，支持私有化部署
- HyDE 增强弱语义查询召回率，动态断崖截断提升答案质量
