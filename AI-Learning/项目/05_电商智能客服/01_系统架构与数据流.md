# 电商智能客服系统 - 系统架构与数据流

## 整体架构

```mermaid
graph LR
    A[前端] --> B[API层]
    B --> C[Service层]
    C --> D[Engine层]
    D --> E[三轨处理]
    
    C --> F[(MySQL)]
    D --> G[LLM API]
    E --> H[电商后端]
```

**分层职责：**

| 层 | 职责 | 关键设计 |
|----|------|---------|
| API 层 | 接收请求、返回响应 | Pydantic 校验 |
| Service 层 | 编排事务（load→process→save） | I/O 隔离 |
| Engine 层 | 核心调度、三轨路由 | LLM 路由 + 白名单校验 |
| 三轨处理 | Task / Knowledge / Chitchat | 各司其职 |

```mermaid
graph TB

    H --> I

```

## Task 轨道流程

```mermaid
graph TB
    A[TaskHandler] --> B[CommandProcessor<br/>改状态]
    B --> C[FlowExecutor<br/>推流程]
    
    C --> D{Step 类型}
    D -->|Start| E[跳到下一步]
    D -->|Collect| F{槽位有值?}
    D -->|Action| G[执行 Action]
    D -->|End| H[结束流程]
    
    F -->|有值| E
    F -->|无值| I[向用户提问]
    
    G --> J[ActionRunner]
    J --> K[内置Action / 业务Action]
    K --> L[更新槽位 + 收集回复]
    L --> C
```

## 请求处理时序

```mermaid
sequenceDiagram
    participant U as 用户
    participant Svc as Service
    participant Eng as Engine
    participant LLM as LLM
    participant DB as MySQL
    
    U->>Svc: 发送消息
    Svc->>DB: 加载状态
    Svc->>Eng: 处理消息
    
    Eng->>LLM: TurnPlanner.predict()
    LLM-->>Eng: TurnPlan
    
    Eng->>Eng: 校验 + 路由 + 执行
    
    Eng-->>Svc: 返回结果
    Svc->>DB: 保存状态
    Svc-->>U: 返回回复
```

## Task 轨道时序

```mermaid
sequenceDiagram
    participant Eng as Engine
    participant Cmd as CommandProcessor
    participant Flow as FlowExecutor
    participant Act as ActionRunner
    participant API as 电商API
    
    Eng->>Cmd: 执行命令（启动/恢复流程）
    Cmd-->>Eng: 状态已更新
    
    Eng->>Flow: run_task()
    
    loop 两层循环
        Flow->>Flow: advance_until_action()
        alt 需要执行 Action
            Flow->>Act: run(action_call)
            Act->>API: fetch_order() / fetch_logistics()
            API-->>Act: 数据
            Act-->>Flow: ActionResult
        end
    end
    
    Flow-->>Eng: messages
```

## Knowledge 轨道时序

```mermaid
sequenceDiagram
    participant Eng as Engine
    participant KH as KnowledgeHandler
    participant P as Provider
    participant API as 电商API
    participant KR as KnowledgeResponder
    participant LLM as LLM
    
    Eng->>KH: handle(intents)
    
    KH->>P: retrieve(state)
    P->>API: 查询商品/订单
    API-->>P: 数据
    P-->>KH: KnowledgeChunk
    
    KH->>KR: respond(chunks)
    KR->>LLM: 生成回复
    LLM-->>KR: 回复文本
    
    KR-->>Eng: messages
```

## 状态管理

### DialogueState 结构

```mermaid
classDiagram
    class DialogueState {
        active_task: TaskContext
        paused_task: 栈
        sessions: Session列表
        pending_turn: Turn
    }
    
    class TaskContext {
        flow_id
        step_id
        slots
    }
    
    class Session {
        turns: Turn列表
    }
    
    DialogueState --> TaskContext
    DialogueState --> Session
```

### 任务栈机制

```mermaid
stateDiagram-v2
    [*] --> 空闲
    空闲 --> 活跃: start_task()
    活跃 --> 空闲: end_task()

    挂起 --> 活跃: resume()
```

## 模块职责表

| 层级 | 模块 | 职责 |
|------|------|------|
| **API** | FastAPI + Router | 接收请求、返回响应 |
| **Service** | DialogueService | 编排事务 |
| **Engine** | DialogueEngine | 核心调度、三轨路由 |
| **Plan** | TurnPlanner + Validator | 意图识别、白名单校验 |
| **Task** | TaskHandler + FlowExecutor | 流程执行 |
| **Knowledge** | KnowledgeHandler + Provider | 知识问答 |
| **Domain** | DialogueState | 状态管理 |
| **Infrastructure** | LLM + HTTP + DB | 基础设施 |
