# 核心模块设计

> 6 个核心模块的设计思路。每个模块用统一模板：**作用 -> 为什么 -> 替代方案 -> 面试追问 -> 核心代码**。

---

## 1. 数据预处理

**作用：** 把原始 CSV 转成模型可用的结构化数据。

**为什么这么做：**
- CSV 有脏数据（空值、格式不一致），必须清洗
- BERT 只接受 input_ids + attention_mask，需要 Tokenizer 编码
- 离线预处理存 Arrow，避免每次训练重复 tokenize（省几十分钟）

**替代方案对比：**

| 方案 | 优点 | 缺点 |
|------|------|------|
| 离线 Arrow（本项目） | 快，训练直接读 | 占磁盘空间 |
| 在线 tokenize | 不占空间 | 每次训练都要重新编码 |
| 预训练 Tokenizer batch encode | 简洁 | 不灵活，难加自定义清洗逻辑 |

**核心代码思路：**

```python
# 1. 清洗
dataset = dataset.filter(lambda x: x['review'] is not None and len(x['review']) > 0)

# 2. encode
def encode_fn(examples):
    return tokenizer(examples['review'], truncation=True, padding=False, max_length=512)
dataset = dataset.map(encode_fn, batched=True)

# 3. 标签固定映射
dataset = dataset.cast_column("label", Value("int64"))

# 4. 保存 Arrow
dataset.save_to_disk("data/processed/")
```

**面试追问：** "为什么用 Arrow 格式？"
> Arrow 是列式存储，HuggingFace datasets 底层格式，读取快、支持内存映射，比 CSV 快一个数量级。

## 2. Dataset / DataLoader

**作用：** 把编码好的数据封装成可迭代的 batch，供模型训练。

**为什么这么做：**
- PyTorch 的 Dataset/DataLoader 是标准数据管道
- `DataCollatorWithPadding` 实现动态 padding，每个 batch 按最大样本长度 pad，而不是全局 pad 到 512

**替代方案对比：**

| 方案 | 优点 | 缺点 |
|------|------|------|
| 动态 Padding（本项目） | 省 40-60% 计算量 | 实现稍复杂 |
| 静态 Padding（pad 到 512） | 简单 | 大量 padding 浪费显存和计算 |
| 自定义 collate_fn | 最灵活 | 需要自己写逻辑 |

**核心代码思路：**

```python
from transformers import DataCollatorWithPadding

collator = DataCollatorWithPadding(tokenizer=tokenizer)
train_loader = DataLoader(train_dataset, batch_size=16, collate_fn=collator, shuffle=True)
```

**面试追问：** "动态 padding 比静态 padding 省多少？"
> 省 40-60%。假设 batch 里最长句子 128 tokens，静态 pad 到 512 意味着每个 batch 有 75% 是无用 padding，attention_mask 直接忽略这些位置，但矩阵运算还是要算的。

## 3. 模型定义

### V1：手动版

**作用：** 自己写模型类，搞清楚 BERT 输出的每一层是什么。

**为什么这么做：** 学习目的，理解 BERT 内部工作方式。

**核心代码：**

```python
class ReviewAnalyzeModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.bert = AutoModel.from_pretrained("bert-base-chinese")
        self.classifier = nn.Linear(768, 1)  # CLS向量 768维 -> 标量

    def forward(self, input_ids, attention_mask):
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
        cls_output = outputs.last_hidden_state[:, 0, :]  # 取CLS向量
        logits = self.classifier(cls_output).squeeze(-1)  # (batch_size,)
        return logits
```

**面试追问：** "为什么取 CLS 向量？"
> BERT 预训练时设计了 Next Sentence Prediction 任务，CLS token 在预训练过程中学会了汇总整句语义。它的输出是整个序列的"摘要"，适合做句子级分类。

### V2：AutoModel 版

**作用：** 用 HuggingFace 封装，省去手动定义模型和损失函数。

**核心代码：**

```python
from transformers import AutoModelForSequenceClassification

model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-chinese", num_labels=2
)
# 损失内置，训练时直接 model(**batch) 拿 outputs.loss
```

**面试追问：** "AutoModelForSequenceClassification 内部做了什么？"
> 它在 BERT 后面加了一个 `nn.Linear(hidden_size, num_labels)` 作为分类头，训练时如果你传了 labels，它内部会自动算 CrossEntropyLoss，输出里同时有 logits 和 loss。

## 4. 训练循环

**作用：** 前向传播 -> 计算损失 -> 反向传播 -> 更新参数 -> 保存最优模型。

**为什么这么做：**
- BCEWithLogitsLoss = sigmoid + BCE 合二为一，数值稳定
- Adam + lr=1e-5 是 BERT 微调的经典组合
- 保存最低 loss 的 epoch 而非最后 epoch，防止过拟合

**V1 vs V2 训练区别：**

```python
# V1: 手动处理
labels = batch.pop('labels')
logits = model(**batch)
loss = loss_fn(logits, labels.float())

# V2: 一行搞定
outputs = model(**batch)  # batch里包含labels
loss = outputs.loss       # 内置计算
```

**面试追问：** "为什么 lr=1e-5？"
> BERT 有 110M 参数，大部分已经预训练好了。学习率太大会破坏预训练知识（灾难性遗忘），太小收敛慢。1e-5 是经验值，在保留预训练知识和适应新任务之间取得平衡。

## 5. 评估

**作用：** 在测试集上算准确率，判断模型泛化能力。

**核心指标：** Accuracy（正负分类准确率）

**面试追问：** "为什么只用 Accuracy？"
> 项目是二分类，数据集标签大致均衡，Accuracy 足够说明问题。实际项目中如果标签不均衡，应该加 Precision、Recall、F1、AUC-ROC。

---

## 6. 预测

**作用：** 模型推理，支持三种模式。

| 模式 | 用途 |
|------|------|
| 单条预测 | 输入一条评论，输出情感+置信度 |
| 批量预测 | 输入多条，批量推理 |
| 交互预测 | 命令行交互，持续输入持续预测 |

**V1 vs V2 预测区别：**

```python
# V1: sigmoid 取概率
prob = torch.sigmoid(model(**inputs)).item()

# V2: softmax 取正类概率
prob = torch.softmax(model(**inputs).logits, dim=-1)[0, 1].item()
```

**面试追问：** "sigmoid 和 softmax 的区别？"
> sigmoid 把单个值压到 [0,1]，适合二分类输出一个概率。softmax 把 N 个 logits 变成概率分布（加起来为 1），适合多分类。数学上，二分类时 sigmoid(x) = softmax([0, x])[1]，结果等价。
