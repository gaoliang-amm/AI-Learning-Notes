# 智能商品发布 — 问题与优化

---

## 常见问题排查

### 1. 过拟合

**表现**：训练 loss 持续下降，验证 loss 上升，验证 accuracy/f1 下降。

**原因**：
- 数据量不足（电商标题分类通常数据量有限）
- BERT 预训练权重过于强大，微调时容易过拟合小数据集
- 缺少正则化手段

**解决方案**：
| 措施 | 效果 |
|------|------|
| Early Stopping（本项目已实现） | 检测到验证集不再提升时停止训练 |
| Dropout（BERT 内置 0.1） | 随机丢弃神经元，防过拟合 |
| Weight Decay（AdamW，本项目可用 Adam 替代） | L2 正则化，限制权重过大 |
| 数据增强 | 同义词替换、回译等增加训练样本 |
| 减小微调轮数 | BERT 微调通常 2-4 epoch 即可收敛 |

### 2. 训练崩溃（AMP 相关）

**表现**：训练 loss 突然变成 NaN/Inf。

**原因**：fp16 数值范围有限（6e-8 ~ 65504），梯度容易下溢。

**解决方案**：
- **GradScaler**（本项目已实现）：放大 loss 使梯度数值更大，更新参数前再缩回来
- 检测到 inf/nan 时跳过此步并降低 scale_factor
- 如果持续崩溃，可关闭 AMP（`amp_enabled=False`）用纯 fp32

### 3. 标签不一致

**表现**：训练时 accuracy 很高但推理结果明显错误。

**原因**：训练时标签 id 映射与推理时不同（`class_encode_column` 顺序不确定）。

**解决方案**：
- **`cast_column` + `sorted(set(labels))`**（本项目已实现）
- `labels.txt` 保存排序后顺序，推理时从文件读取
- `id2label`/`label2id` 写入模型 config，`save_pretrained` 后推理无需外部文件

### 4. Padding 效率低

**表现**：训练速度慢，GPU 利用率低。

**原因**：静态 padding 到固定长度（如 512），大部分 token 是 padding，BERT attention 在无用 token 上浪费计算。

**解决方案**：
- **`DataCollatorWithPadding`**（本项目已实现）：每个 batch 动态 pad 到该 batch 最长序列
- 预期节省 40-60% 计算量

## 优化路径

### 短期优化（可快速实现）

| 优化项 | 具体做法 | 预期收益 |
|--------|---------|---------|
| Optimizer | Adam → AdamW（weight_decay=0.01） | 正则化，减少过拟合 |
| Scheduler | 添加 linear warmup + cosine decay | 训练更稳定 |
| Gradient Clipping | `torch.nn.utils.clip_grad_norm_(max_norm=1.0)` | 防止梯度爆炸 |
| num_workers | DataLoader 增加多进程加载 | 数据加载不再成为瓶颈 |
| logging | tqdm.write → logging 模块 | 支持文件输出，方便排查 |

### 中期优化（需要一定工作量）

| 优化项 | 具体做法 | 预期收益 |
|--------|---------|---------|
| 数据增强 | 同义词替换、随机删除、回译 | 增加训练样本多样性 |
| 模型蒸馏 | BERT → 小模型（如 TinyBERT） | 推理速度快 3-5 倍 |
| Top-K Checkpoint | 保存 top-5 最优模型而非最新 | 更鲁棒的模型选择 |
| YAML 配置 | Training_Config 支持从 YAML 加载 | 超参数管理更灵活 |

### 长期扩展（工业级）

| 优化项 | 具体做法 | 预期收益 |
|--------|---------|---------|
| 分布式训练 | DDP（torch.distributed） | 多卡加速 |
| 模型量化 | INT8/INT4 量化 | 推理显存减半 |
| A/B 测试 | 线上灰度验证模型效果 | 数据驱动决策 |
| 数据飞轮 | 线上错误case 回流训练集 | 持续提升 |

## 扩展方向

### 更多数据增强

```python
# 同义词替换
import random
from synonyms import get_synonyms

def synonym_replacement(text, n=1):
    words = list(text)
    new_words = words.copy()
    random_indices = random.sample(range(len(words)), min(n, len(words)))
    for idx in random_indices:
        synonyms = get_synonyms(words[idx])
        if synonyms:
            new_words[idx] = random.choice(synonyms)
    return "".join(new_words)
```

## 面试追问

> Q: 如果训练时 loss 不下降怎么办？
> A: 排查顺序：1) 检查学习率是否太大（尝试 1e-5）；2) 检查标签映射是否正确（打印几个 batch 的 labels）；3) 检查数据是否加载正确（打印 input_ids 和对应文本）。

> Q: 如何判断模型是否过拟合？
> A: 监控训练 loss 和验证 loss 的差值。如果训练 loss 持续下降但验证 loss 上升，说明过拟合。也可观察 accuracy/f1 的训练/验证差距。
